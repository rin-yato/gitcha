## Findings considered and rejected

- **Config frozen at module import time**: By-design — standard CLI behavior. Runtime hot-reload of config is not needed for a TUI.
- **ExPromptCommand `unknown` fields**: Intentional defensive pattern against upstream `@opentui/keymap` type changes. Runtime guards serve as graceful degradation.
- **Context provider API objects recreated every render**: SolidJS context consumers subscribe to specific store properties, not the context object itself. Low impact.
- **`diff` library only used for `parsePatch` — potential bundle weight**: Theoretical without bundle measurement. Bun tree-shakes. Not worth action.
- **`conventional-commits-filter`/`parser` as devDependencies**: Transitive deps of `@release-it/conventional-changelog`; explicit listing is harmless.
